# 万圣夜：第七教学楼

一款在浏览器里运行的 Q 版怪诞校园第一人称探索游戏。晚会散场后，三名布置小组的同学还在教学楼里，你要找到他们，一起回家。

打开即玩，无需安装、无需注册、无后端依赖。

## 怎么玩

- 电脑：WASD 移动，鼠标观察，左键射击，E 互动，R 换弹，Q 南瓜弹，C 糖果，F 手电，M 或 Tab 地图，Esc 暂停。
- 手机：横屏后左侧摇杆移动，右侧拖动观察，右下角按钮射击与互动。
- 建议第一次选「氛围模式」：资源充足、辅助瞄准、轻松探索。

## 一局的流程

找地图 → 救三名同学 → 拿到钥匙与保险丝 → 恢复广播 → 限时防守 → 返回大厅结局。保安室是安全屋，僵尸不会进入，进度会自动保存。

## 设计边界

无血腥、无跳脸、无频闪、无排行榜。恐怖来自门后的未知，而不是伤口。
